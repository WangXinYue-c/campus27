云端同步 Supabase · 多设备实时同步

    

      
      
      
岗位数据按条合并（最新修改优先）；简历与定制稿以云端为准。API Key 不会上传。连接失败自动降级为离线模式，本地修改不丢。

    

    

      云端初始化（一次性，仅首次部署时需要）：

      ① 打开 Supabase 控制台 → 左侧「SQL Editor」→ 粘贴以下语句并 Run：

      create table if not exists campus27_jobs (id text primary key, data jsonb, ut bigint default 0, deleted boolean default false);
alter table campus27_jobs disable row level security;
create table if not exists campus27_kv (k text primary key, v jsonb, ut bigint default 0);
alter table campus27_kv disable row level security;

      ② 把本页面上传到任意静态托管（如 Supabase Storage / EdgeOne Pages / GitHub Pages），用网址访问，多设备打开即数据互通

      · Key 仅保存在本机浏览器 localStorage，不会上传到任何服务器

      · LLM 已按你的阿里云百炼（通义千问）Key 预设好 Base URL 和模型名，只需填入 Key 即可；也兼容 DeepSeek / 智谱 GLM 等 OpenAI 格式服务商

      · 定制一份简历约消耗几分钱；搜索每次约 0.05 元

      · 若调用报「网络错误 / Failed to fetch」，多为该服务商不允许浏览器直连（CORS 限制），换一家服务商即可

      · 把页面分享给亲友时，对方读不到你浏览器里的 Key（本地存储隔离），需各自配置；云端地址已随页面内置，无需重复填
