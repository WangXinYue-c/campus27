# 27届校招工作台

个人求职管理工作台——单文件 HTML，打开即用，手机电脑双端适配。

## 功能

- **14 态投递流程**：待投递 → 已投递 → 笔试 → 一~三面 → 待实习 → 实习中 → Offer（含已终止），看板一键推进
- **今天要处理**：逾期 / 临期 / 待跟进自动置顶
- **看板总览**：Pipeline 全景 + 单公司聚合，点击直达
- **投递时间**：表单填写或状态变更自动记录
- **云端同步**：Supabase PostgREST，多设备实时同步 + 断网本地缓存自动补传
- **AI 能力**：阿里百炼简历定制与岗位匹配、Tavily 岗位情报搜索

## 使用

直接打开 `index.html` 即可。数据存于浏览器 localStorage 并通过 Supabase 同步。

## API 配置（设置面板）

| 服务 | 用途 | 说明 |
|------|------|------|
| Supabase | 云端数据库 | URL 与 anon key 已预置 |
| 阿里百炼 | AI 简历匹配 | 自行填入 API Key |
| Tavily | 联网搜岗位 | 自行填入 API Key（**不随仓库分发**） |

## 安全说明

- Tavily Key 已从公开版本中移除，请在页面「设置 - API 设置」中自行填入
- Supabase anon key 为公开客户端密钥，数据表当前未启用行级安全（RLS），请勿在公开分享场景存放敏感数据
